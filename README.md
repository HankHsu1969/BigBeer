# Big Beer 啤酒節大合杯

這是一款以慕尼黑啤酒節為主題的合成物理遊戲，玩法類似《西瓜遊戲》，但改成從桌子前端把啤酒杯往後推。桌面朝遠端微微傾斜，重力會把杯子拉向遠端。兩個一樣的杯子撞在一起會合成更大的杯子；杯子堆過紅線太久，遊戲就結束。

## 怎麼開始

直接用瀏覽器（Chrome、Edge、Safari、Firefox）開啟 `index.html` 即可，不需要安裝任何東西。

也可以開一個本機伺服器再連進去：

```bash
python -m http.server 8765
```

然後打開 http://localhost:8765 。

## 刺激元素

- **沒耐心的服務生**：每一杯都要在倒數內推出去。一開始有 7 秒，越玩越短，最短 3.2 秒。時間到了她會自己幫你推，推到哪就看運氣。
- **帳篷事件**：每 13～20 秒隨機發生一次，越玩越頻繁。
  - 全場搖擺（Schunkeln）：整張桌子左右搖晃，杯子會跟著左右滑動。
  - 拍桌乾杯（Oans, zwoa, g'suffa!）：三次拍桌，所有杯子被震得跳起來、到處亂跑。
  - 請喝一輪（Eine Runde Schnaps!）：好幾個烈酒杯從天而降，砸進杯堆裡。
  - 免費啤酒（Freibier!）：10 秒內分數加倍。
- **越來越快的樂隊**：樂隊節奏會隨遊戲時間加快；杯子越過紅線時會再加速。

## 11 階進化圈

小烈酒杯 → 小啤酒杯 → 皮爾森杯 → 小麥啤酒杯 → 黑啤酒杯 → 一公升大杯 → 陶瓷啤酒壺 → 錫蓋啤酒杯 → 啤酒靴 → 小酒桶 → 巨型酒桶。兩個巨型酒桶相撞會一起消失，並拿到大筆加分（Ein Prosit!）。

## 技術說明

- **物理**：`js/physics.js` 是自製的 2D 剛體解算器，處理桌面平面上的碰撞，包含傾斜桌面的重力、滑動摩擦、帶反彈與切向摩擦的衝量碰撞，以及合成判定。另有一條垂直（z 軸）通道，讓杯子被撞跳起、合成彈出和泡沫飛濺都受真實重力影響。
- **畫面**：`js/render.js` 用針孔透視投影繪製桌面。桌面木紋逐行貼圖以保持透視正確。被前方杯子擋住的杯子會以半透明「玻璃透視」顯示。橫式與直式（手機）螢幕都支援。
- **音樂**：`js/music.js` 用 Web Audio 即時合成原創的巴伐利亞「嗡吧吧」波卡舞曲，包含低音號、手風琴、三度和聲小號、單簧管、鐘琴和鼓。
- **音效**：`js/audio.js` 用模態合成即時產生各種聲音：玻璃杯清脆的碰撞聲、陶瓷壺的悶響、木桶的敲擊聲、桌面滑動的摩擦聲、啤酒氣泡聲、群眾歡呼與掌聲、牛鈴警告聲、帳篷殘響，以及合成時的「Prost!」碰杯聲。
- **美術與語音**：圖片由 Higgsfield（H站）的 GPT Image 2 產生並去背；德語喊聲（Prost!、O'zapft is!、Oans, zwoa, g'suffa! 等）由 Higgsfield TTS 產生。
- **素材處理**：`assets/raw/` 存放原始生成檔。執行 `python tools/build_assets.py` 會重新裁切、壓縮，並量測每個杯子的杯底位置，輸出到 `assets/img/` 與 `js/sprites-meta.js`。

網址加上 `?debug` 會顯示碰撞範圍和 FPS。
